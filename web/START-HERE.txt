Wiktionaries per Word - snapshot assembled 2026-10-23

This folder contains the static explorer, all language data, full/per-language downloads, source metadata and checksums. This is a one-time, unmaintained release; no support or updates are planned.

With Python installed, open a terminal in this extracted folder:
    python -m http.server 8765 --bind 127.0.0.1
Use python3 if that is your Python command. Open http://127.0.0.1:8765/ in a browser. Direct file:// opening is unsupported because modules/workers load packaged files over HTTP. No Node installation or regeneration is needed to explore the data.

Choose an entry language, search an exact form or prefix, and click column headings to sort the complete result. Choose entries per page, or type a number in Page and press Enter/Go. Next and Previous remain available. Rankings do not change when search filters the view.

Full downloads are in snapshots/2026-10-23-first/downloads/:
    full-scores.csv.gz - all language/form counts and tied ranks
    full-evidence.csv.gz - contributing editions and original JSONL line pointers
    full-scores.sqlite.gz - portable database with scores and provenance
Language filenames are mapped in snapshots/2026-10-23-first/languages.json.

Read documentation/METHODOLOGY.md, documentation/LICENSE.md and documentation/NOTICE.md. Raw codes and exact spellings are preserved. Counts measure editorial coverage, not corpus frequency or validated learning utility. Source dates differ; all 21 source editions have equal weight, including an entry language's own edition.

artifact-inventory.json contains per-file sizes and SHA-256 checksums. validation/ contains historical checks and code/runtime provenance. Later explorer checks include rendered Chrome verification of pagination, direct page jumps, sorting and search. Original source archives are not included.
